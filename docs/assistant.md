# Jev 網頁搜尋助手（v2）

`uv run jev` 後打開 **http://127.0.0.1:8767**。這是 v1 任務台的進階版，三層分工：

| 層 | 誰做 | 做什麼 |
| --- | --- | --- |
| 規劃 | 規劃模型（預設 Claude Sonnet 5，`PLANNER_MODEL`） | 讀懂中文任務、決定意圖與收錄欄位、拆成步驟。結果先顯示給你確認 |
| 執行 | Jev（互動）＋ 程式（導航） | 打字、送出搜尋等互動交給 Jev；開網址、逐一處理由程式直接做，不讓 Jev 點錯 |
| 判斷與收錄 | 判斷模型（預設 Gemini 2.5 Flash，`JUDGE_MODEL`） | 從頁面連結挑出符合條件的候選、把每頁抽成結構化欄位、最後寫報告 |

## 步驟類型

- `browse`：Jev 在目前分頁上操作，英文目標由規劃模型直接產生（關鍵字保留中文）。
- `navigate`：直接開網址。
- `collect_candidates`：程式讀取頁面所有連結，判斷模型依條件挑出商品／貼文頁，最多 N 個。
- `foreach_candidate`：逐一開啟候選網址，執行子步驟（通常就是 `capture`）。
- `capture`：收錄本頁。存網址、標題、抽取欄位（商品：名稱、品牌、尺寸、價格、片數、單價說明、賣家、促銷、規格、供貨、是否符合、原因、摘要）與截圖。
- `report`：用所有收錄產出中文報告（比較表、不符合清單、結論）。

## 收錄存在哪裡

`artifacts/collections/<任務代號>/`：`records.json`、`records.csv`（Excel 可直接開）、`report.md`、每筆一張 `NN.jpg`。介面也能直接匯出 CSV／JSON。

## 用量

面板分開顯示 Jev、文字模型、規劃模型、判斷模型的呼叫次數與費用，以及 OpenRouter 即時餘額。Jev 沒有餘額 API，剩餘額度以預付金額扣本機累計估算。

## 限制

- 反爬或需要登入的網站（酷澎、Threads）可能開不完整或被擋，收錄會標記失敗但流程會繼續。
- 商品頁若是純圖片內容，抽取欄位會是 null。
- v1 單步任務台仍在 `/console`，原始英文示範在 `/en`。

## 第二輪新增（2026-09-24）

- **多網站**：任務區改為勾選多個網站，同一組關鍵字在每站各搜一輪，收錄會標記來源網站，報告是跨站比較表。
- **多關鍵字與學習**：規劃模型先產 3 至 5 組關鍵字變體（可在規劃卡片直接增刪）；首輪搜完後，判斷模型會從已找到的標題學出正式品牌／系列名（例如使用者打「水凝尿布」，商品其實叫「Parasol Clear+Dry」），再追搜一輪。
- **結果展開與翻頁**：每頁先捲動到連結數不再增加，再翻頁最多 N 頁（規劃卡片可調），候選用網域＋路徑＋商品編號去重。
- **搜尋方式**：一律由 Jev 在站內搜尋框打字並送出（2026-10-01 起固定，已移除切換勾選框）。第 2 頁以後的翻頁仍由程式開搜尋網址。
- **報告知識庫**：每次任務完成自動寫入 `reports/日期_關鍵字_網站.md`，檔頭有任務、條件、關鍵字、網站、筆數、費用、耗時，內文含搜尋過程、報告、收錄清單與截圖路徑；`reports/index.md` 是總目錄。介面的「歷史報告」可直接開啟舊報告。
