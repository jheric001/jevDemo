# 繁體中文任務台

`uv run jev` 之後，打開 **http://127.0.0.1:8766** 就是繁體中文任務台（介面全中文，只保留 Jev、momo、OpenRouter 這類專有名詞）。
原始的英文示範頁移到 http://127.0.0.1:8766/en，介面上不再連結。

## 它做了什麼

1. **中文下任務**：你用中文描述要做的事，按「開始任務」時文字模型會自動把它改寫成一句給 Jev 的英文指令，
   搜尋關鍵字、商品名、品牌、網站名等會保留原文並加上引號，所以打進網站搜尋框的仍然是中文。
   想先看或修改改寫結果，展開「進階」區塊；勾選「不改寫」可以直接把中文交給 Jev 做對照實驗。
   核心程式回傳的英文錯誤訊息也會在介面上換成中文說明。
2. **起始網站預設**：momo、PChome 24h、酷澎、Google 搜尋、Google Flights、維基百科，或自訂網址。
3. **用量與額度面板**：
   - 本次任務：Jev 決策次數、輸入 token、估算費用；文字模型呼叫次數與費用；動作數與耗時。
   - Jev 累計（本機估算）：所有任務加總的請求數、token、費用。TypeSafe 沒有餘額 API，
     所以「估算剩餘」是用你填的預付金額扣掉本機累計，正確餘額請看 console.typesafe.ai。
   - OpenRouter（即時）：帳戶總額、已用、剩餘，以及這把金鑰的上限與用量，每 20 秒自動更新。
4. **最近的任務**：最近 8 個任務的用量摘要，資料存在 `artifacts/usage-ledger.json`（已在 .gitignore）。

## 設定

`.env` 可加的選項：

```
TRANSLATE_MODEL=google/gemini-2.5-flash-lite   # 翻譯用模型，未設定時沿用 TEXT_MODEL
JEV_PREPAID_USD=20                              # 你在 TypeSafe 預付的金額，用來估算剩餘
JEV_USD_PER_MTOK=0.042                          # Jev 單價，官方調價時改這裡
```

改完 `.env` 要重啟 `uv run jev`，而且要**重新整理瀏覽器分頁**（每次啟動的安全 token 不同，舊分頁會被 403 擋下）。

## 目前的限制

- Jev 的 DOM 讀取器是 MVP，看不到 iframe、Shadow DOM、canvas，以及部分視覺隱藏的 radio 選項（例如 Google
  Flights 的「轉機次數」對話框）。任務請以「填欄位、送出搜尋、看到結果就停」為主，篩選與排序先自己點。
- Jev 說 DONE 不代表任務真的成功，請看頁面結果。
- 它是用你目前登入的 Chrome 操作，測試時建議用乾淨的 Chrome 設定檔。
